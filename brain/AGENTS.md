# Project brain

This folder is the durable memory for **this** repo. Global facts live in `~/work/brain` — do not copy them here.

## Load

Do not read this folder by default. If you lack product/stack/focus: `INDEX.md`, then **≤2 pages**. Prefer `rg`.

## Where to write

| Happened | File |
|---|---|
| What this product is / is not | `brief.md` |
| Why it exists | `product.md` |
| How the code is shaped | `architecture.md` |
| Stack, commands, gotchas | `stack.md` |
| What we are doing right now | `active.md` |
| What works / what's left | `progress.md` |
| A locked-in choice | `decisions/<slug>.md` |
| A lesson for *this* repo | `learnings/<slug>.md` |
| A lesson that should change every repo | `~/work/brain/learnings/` + link from here |

Update `INDEX.md` when you add a page. Keep `active.md` current; it is the file that goes stale first.

After a decision, gotcha, or scope change: write here **before you stop**. `/learn` works in every repo. Do not invent lessons.

No secrets. No chat logs. No README clones.
